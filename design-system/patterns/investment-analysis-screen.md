# Investment Analysis Screen Pattern

## Mobile과 Web 역할

| 영역 | 역할 |
|---|---|
| Mobile | 빠른 판단, 관계 확인, 근거 요약, Web 이동 |
| Web | 깊은 분석, 원문 탐색, 재무/산업/기업 상세 분석 |

## Mobile에 남길 정보

- Event가 무엇인지
- 어떤 Asset과 관련 있는지
- 내 보유/관심과 어떤 관계인지
- 지금 추가 확인이 필요한지
- 판단 근거가 무엇인지
- 근거가 부족하거나 오래됐는지
- 더 깊게 보려면 어디로 가야 하는지

## Mobile에서 접거나 보내야 할 정보

- 긴 뉴스 본문
- Full transcript
- 세부 재무표
- 대형 차트
- 복수 기간 비교표
- 리스크 팩터 전체 목록
- 계좌/보유 수량/평가금액 등 민감 정보

## Information Density

모바일 첫 화면은 다음을 피합니다.

- 카드 과다
- Badge 과다
- CTA 경쟁
- 차트와 표의 동시 노출
- Web 분석 메뉴를 그대로 축소한 구조

첫 화면은 “판단”을, 아래 영역은 “검증”을, Web은 “분석”을 담당합니다.
