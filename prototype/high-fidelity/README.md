# High-fidelity Prototype

This folder contains mobile high-fidelity frames for `Portfolio-aware Event Triage`.

## Scope

- Product SoT: `docs/DESIGN.md`
- Design reference: `design-system/`
- Production: `BLOCKED`

## Frame Set

The prototype supports 15 state variants through the `state` query parameter:

```text
normal
watchlist
insufficient
related
multiple
unconnected
partial
empty
stale
source
permission
error
loading
handoffFail
handoffSuccess
```

Example:

```text
index.html?state=normal
```

## Viewport QA

Screenshots are generated by `scripts/high-fidelity-qa.js` into `artifacts/high-fidelity/`.

Required viewports:

- 360x800
- 390x844

Stress viewport:

- 320x800
